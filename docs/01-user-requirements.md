## 1.1 用户操作流（Phase1 Demo）

| Flow ID | 参与角色 | 前置条件 | 步骤 | 成功路径 | 失败 / 中断路径 | 覆盖 U-ID |
|---|---|---|---|---|---|---|
| UFlow-001 | R-001 / R-002 | 用户已登录且属于至少一个空间 | 登录 → 查看当前空间 → 切换空间 | 只看到当前空间内容，搜索 / 问答随空间切换 | 无权限空间不可访问 | U-01 / U-02 / U-03 |
| UFlow-002 | R-001 / R-002 | 有已提取文本资料 | 导入 `.md` / `.txt` → 生成文档 → 切块入库 | 文档可搜索、可问答引用 | 空文件 / 不支持文件按错误提示处理；真实 Word / PDF / OCR 不作为 P1 必过 | U-09 / U-10 |
| UFlow-003 | R-002 / R-003 | 空间已有文档和索引 | 输入关键词或语义问题 → 查看搜索结果 / 问答答案 | 结果带标题、摘要、定位和来源；无相关内容时明确未找到 | 无权限文档不出现；库外问题不编造 | U-07 / U-08 |
| UFlow-004 | R-001 / R-002 | 已有可编辑文档 | 创建 / 编辑文档 → 保存 → 查看版本 → 恢复版本 | 内容持久、历史版本可见并可恢复 | 无权限编辑被拒绝 | U-04 / U-05 / U-06 / U-12 |
| UFlow-005 | R-001 / R-003 | 空间已有术语或需新建术语 | 创建术语 → 文档识别 → 问答优先使用空间定义 | 同名全局术语不覆盖空间术语 | 待确认术语不阻断编辑 | U-42 |
| UFlow-006 | R-001 / R-002 / R-003 | 用户使用桌面浏览器 | 在 Chrome / Edge 完成导入、搜索、问答、编辑、版本和术语流程 | 桌面端主流程无阻断 | 移动端不作为 Phase1 验收 | U-11 |
