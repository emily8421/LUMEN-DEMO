# 印象笔记（桌面客户端）前端交互设计需求说明文档

## 1. 文档说明

本文档基于"印象笔记"桌面客户端界面截图整理，用于描述其整体布局、核心功能模块、交互逻辑与视觉风格规范，作为知识管理类产品设计的参考对照（区别于前述"知识库 Wiki"的图谱式知识库，本产品为**传统三栏式笔记管理工具**）。

---

## 2. 产品概述

印象笔记是面向个人/科研场景的**结构化笔记与知识管理工具**，核心定位是"分类归档 + 富文本记录 + AI 辅助创作"。从截图内容看，用户将其用作**科研笔记系统**，笔记本层级围绕研究方法、文献、数据、答辩等科研全流程组织，体现出强"知识分类树 + 长文本沉淀"的使用特征，区别于 Wiki 类产品的"图谱探索"体验。

---

## 3. 整体页面布局

页面采用经典的**三栏式桌面应用布局**（类 Outlook/Evernote 结构），从左到右分别为：笔记本导航栏、笔记列表栏、笔记编辑区，顶部另有菜单栏与工具栏。

| 区域 | 位置 | 主要内容 |
|---|---|---|
| 标题栏 | 窗口最顶部 | 应用图标、当前笔记标题、窗口控制按钮（最小化/最大化/关闭） |
| 菜单栏 | 标题栏下方 | 文件、编辑、查看、笔记、格式、工具、帮助 |
| 顶部工具条 | 菜单栏下方右侧 | 前进后退、刷新、通知、分享、表情、隐私保护、更多、侧边栏折叠、AI 入口、用户头像 |
| 第一栏：导航栏 | 页面最左侧 | 新建笔记入口、印象 AI 功能、快捷方式、全部笔记、笔记本树 |
| 第二栏：笔记列表栏 | 中左侧 | 当前笔记本名称、笔记总数、排序/视图切换、搜索框、笔记卡片列表 |
| 第三栏：编辑区 | 右侧主区域 | 笔记标题、元信息（标签/日期）、富文本工具栏、正文编辑区、底部标注工具 |

---

## 4. 核心功能模块

### 4.1 菜单栏与顶部工具条
- **菜单栏**：文件(F)、编辑(E)、查看(V)、笔记(N)、格式(O)、工具(T)、帮助(H)，遵循传统桌面软件的功能组织习惯，覆盖全部核心操作的完整入口（区别于移动端/Web端的图标化设计）。
- **顶部工具条**：
  - 前进/后退箭头：笔记浏览历史导航；
  - 刷新图标：同步最新数据；
  - 通知铃铛：消息提醒；
  - 分享/导出图标：笔记外发；
  - 表情图标：情绪标注或快捷表情插入；
  - 盾牌图标：隐私/加密保护提示；
  - "…"更多操作；
  - 侧边栏折叠按钮：控制左侧导航栏显示/隐藏；
  - **"印象AI"入口**：产品级 AI 能力总入口（与列表内嵌"AI帮我写""AI帮我读"呼应）；
  - 用户头像：账户信息与登录状态。

### 4.2 左侧导航栏（第一栏）
- **新建笔记 / 新建超级笔记**：绿色高亮按钮置顶，强调"创建"是最高频操作；"超级笔记"推测为富媒体/多模块笔记（区别于普通文本笔记）的增强创建入口。
- **印象 AI 功能组**：
  - AI帮我写：AI 辅助内容生成/续写；
  - AI帮我读：AI 辅助长文摘要/要点提炼。
- **快捷方式**：用户自定义的高频笔记本/标签快捷入口。
- **全部笔记**：跨笔记本的全局笔记视图。
- **笔记本树（核心信息架构）**：
  - 一级笔记本：0-Lix、0-Mai-Lelight、0-Maizi、0-Maizi-private、0-Maizi-研究（当前展开）、0-Nils、0-NZ、0-SKY宇 等，采用"编号+项目/主题名"的个人化命名规则；
  - 二级子笔记本/标签（以"0-Maizi-研究"展开为例）：M-答辩相关、M-方法指导、M-概念、M-工具收集、M-工作汇报、M-开题相关、M-流量样本收集、M-日志、M-软件使用、M-实验、M-收藏待整理、M-数据集、M-数据解读、M-文献&笔记、M-文献查询、M-学位论文、M-源码、M-重拾、M-重要文献笔记，以及"研究路上""一路走来"两个特殊分类；
  - 每个子分类右侧展示**笔记数量角标**（如"113""10""183"），便于用户快速感知各分类的知识沉淀密度。

### 4.3 中间笔记列表栏（第二栏）
- **笔记本名称 + 下拉切换**：当前视图定位（如"0-Maizi-研究"），支持下拉切换至其他笔记本。
- **笔记总数展示**：如"1330条笔记"，直观呈现知识库规模。
- **排序/视图切换图标**：支持列表/卡片等视图模式及排序方式切换。
- **搜索框**：占位提示"搜索笔记(F6)"，支持快捷键唤起，体现桌面软件的效率设计传统。
- **笔记卡片列表**：
  - 每张卡片包含：标题（蓝色高亮，如"[研究思维]☆李老师：研究的一系列术语及其概念解释"）、正文预览摘要（灰色小字，2-3行截断）、创建/更新日期；
  - 首条笔记卡片带缩略图预览（脑图/示意图小图），其余为纯文字卡片；
  - 标题普遍带有**自定义分类前缀**（如"[研究思维]""[研究路上]"），是用户手工建立的二级分类体系，弥补笔记本颗粒度之外的主题标注需求。

### 4.4 右侧笔记编辑区（第三栏，核心内容区）
- **笔记元信息栏**：笔记图标、所属标签下拉（如"M-方法指导"）、更新时间（"2026/7/2 14:55"）、附件/标签图标、**"查看历史版本"**按钮（版本追溯能力）、分享、协作者、更多操作。
- **富文本编辑工具栏**：功能高度完整，涵盖：
  - 段落样式（印象AI 样式下拉）、字体（微软雅黑）、字号（12）；
  - 字符样式：颜色、加粗、斜体、下划线、删除线、超链接、代码块；
  - 列表：无序列表、有序列表、任务清单（checkbox）；
  - 对齐方式、缩进/取消缩进；
  - 插入：表格、分割线、附件、图片、超链接；
  - 印章/图章图标（可能用于批注/审阅标记）；
  - 锁定图标（笔记加密/只读保护）；
  - 更多操作"…"。
- **正文内容区**：支持高度结构化的富文本排版，从截图内容可见：
  - 标题层级（大标题+副标题）；
  - 引用块（斜体+缩进，用于名人名言引用，如"海森堡"引言）；
  - 加粗强调关键术语（如"系统""事件""关系"）；
  - 项目符号列表（多级）；
  - 图文混排的公式/伪代码记号（如 `S = ⟨A, R⟩`、集合表示 `A = {a1, a2, ..., an}`）；
  - 整体呈现"学术笔记/研究方法论沉淀"的重度文本编辑场景，而非轻量速记。
- **底部标注工具条**：
  - "添加标签…"：自由标签输入；
  - 锁形图标：笔记加密标记；
  - **"对象+""特征+""问题+"**：三个特殊的结构化标注按钮，推测为该用户/团队自定义的**知识结构化拆解框架**（将笔记内容归类为"研究对象、特征、问题"三要素），是较有特色的科研笔记方法论固化到产品交互中的设计。

## 5. 视觉风格规范

| 维度 | 说明 |
|---|---|
| 整体风格 | 传统桌面生产力软件风格，信息密度高、功能入口完整，专业感强于轻量感 |
| 主色调 | 绿色（新建笔记按钮）+ 蓝色（链接/笔记标题/AI 入口），形成"创建=绿、内容/智能=蓝"的色彩语义 |
| 背景色 | 三栏均为浅灰/白色背景，通过极细分隔线区分栏目，视觉克制、不抢内容焦点 |
| 字体排版 | 正文默认"微软雅黑"，字号可调（默认12），支持多级标题、加粗、斜体等丰富排版手段，满足长文写作需求 |
| 图标风格 | 线性图标为主，尺寸小、密度高，符合专业软件"功能优先于美观"的设计取向 |
| 层级区分 | 笔记本树通过缩进+展开箭头体现层级；笔记列表通过卡片+分类前缀体现主题；编辑区通过字号/加粗体现内容层级 |

## 6. 交互细节与体验要点

1. **三栏联动**：左侧选择笔记本 → 中间刷新对应笔记列表 → 点击笔记卡片 → 右侧加载笔记详情，是标准的树状导航到内容详情的联动模式，符合用户对桌面软件的固有认知（低学习成本）。
2. **AI 能力嵌入编辑流**："AI帮我写""AI帮我读"与富文本工具栏中的"印象AI"样式入口相互呼应，AI 被设计为**写作辅助/阅读理解辅助**，而非独立对话窗口（区别于前一份 Wiki 文档中"聊天式 AI 助手"的产品形态）。
3. **强分类而弱图谱**：本产品完全依赖**笔记本树 + 标题前缀 + 标签**的多层显式分类体系来组织知识，未见类似"知识图谱/气泡"的关系发现型交互，检索主要依赖搜索框与笔记本层级点选。
4. **版本与安全并重**："查看历史版本""锁定/加密"等功能在多处出现，说明产品对长期科研笔记的**可追溯性与隐私保护**有较高要求。
5. **自定义结构化标注**：底部"对象+""特征+""问题+"按钮体现产品支持用户自定义结构化知识拆解框架，是从"自由写作"进阶到"结构化知识管理"的关键交互设计，建议在文档中重点标注其可配置性（是否为系统预设三分类还是用户自建标签）。

## 7. 待确认/待优化事项（建议）

- [ ] "超级笔记"与普通笔记的功能边界及使用场景需要产品明确说明，避免用户创建时选择困难。
- [ ] "对象+""特征+""问题+"三个标注按钮的数据结构（是否可增删自定义类型、是否支持跨笔记聚合检索）需要补充说明。
- [ ] 笔记本树层级较深（二级分类达20+项）时的可视化优化建议：增加搜索过滤、拖拽排序或收起分组等能力，缓解长列表的浏览负担。
- [ ] AI 能力（帮我写/帮我读）与右侧富文本编辑器的具体交互方式（弹窗、行内建议、侧边栏对比等）需要进一步设计说明。
- [ ] 移动端/网页端与当前桌面端在功能对等性上的差异需要补充跨端一致性说明。
- [ ] 加密/锁定笔记的权限体系（个人级、团队共享级）需要明确。

## 8. 与"知识库 Wiki"产品的对比参考

| 维度 | 知识库 Wiki | 印象笔记 |
|---|---|---|
| 核心知识组织方式 | 图谱式气泡探索 + 分类目录 | 笔记本树 + 标题前缀 + 标签 |
| AI 能力形态 | 独立聊天式悬浮助手（含"基于知识库"开关） | 嵌入写作流程的"帮我写/帮我读" |
| 内容颗粒度 | 面向团队协作的文档/术语条目 | 面向个人/科研的长文本笔记 |
| 视觉风格 | 卡片化、色彩丰富、Web轻量风格 | 信息密集、功能完整、传统桌面软件风格 |
| 检索方式 | 全局搜索 + 图谱浏览 | 全局搜索 + 笔记本层级点选 |
