# 知识库 Wiki 前端交互设计需求说明文档

## 1. 文档说明

本文档基于现有产品界面截图整理，用于描述"知识库 Wiki"前端页面的整体布局、核心功能模块、交互逻辑与视觉风格规范，作为后续设计、开发、验收的参考依据。

---

## 2. 产品概述

知识库 Wiki 是面向研发/技术团队的内部知识管理平台，核心定位是"从分类、图谱和搜索入口浏览团队知识"。产品主打三种知识获取路径：

1. **分类目录浏览**——通过左侧树形目录逐级查找文档；
2. **知识图谱探索**——通过首页气泡图谱直观发现关联知识点；
3. **AI 智能问答**——通过右下角 AI 助手基于知识库内容进行问答。

---

## 3. 整体页面布局

页面采用经典的"顶部导航 + 左侧目录树 + 中间主内容区 + 右下角悬浮 AI 助手"三段式布局，具体分区如下：

| 区域 | 位置 | 主要内容 |
|---|---|---|
| 顶部导航栏 | 页面顶部，固定 | Logo、全局搜索框、语言切换、通知、帮助、用户头像 |
| 左侧目录栏 | 页面左侧，可收起 | 分类目录树、项目空间入口 |
| 主内容区 | 页面中部，自适应 | 欢迎语、知识图谱可视化、快捷操作工具栏 |
| 底部状态栏 | 页面底部 | 团队标语/公告 |
| AI 助手悬浮窗 | 右下角，可展开/收起 | 智能问答对话框 |

---

## 4. 核心功能模块

### 4.1 顶部导航栏
- **Logo + 产品名**：左上角展示"知识库 Wiki"品牌标识，点击可返回首页。
- **全局搜索框**：位于导航栏中央偏左，占位提示"搜索术语、分类…"，支持术语和分类的模糊搜索。
- **功能图标区**：搜索框右侧依次排列若干功能图标（如导出、权限/加密、新建等，具体含义待与产品确认）。
- **语言切换**：下拉选择"中文"等界面语言。
- **消息通知**：铃铛图标 + 未读消息数角标（如"4"）。
- **帮助入口**："?"图标，提供帮助文档或引导。
- **用户信息**：右上角展示用户头像与用户名（如"maixh"），用于个人中心/登出等操作。

### 4.2 左侧分类目录
- 采用**树形结构**，一级目录以文件夹图标呈现，可展开/折叠（如"研发中心""新手园地""13G专项文件""产测专项""嵌入式周例会""遥控器协议""道韦专项文件"等）。
- 部分目录条目带有特殊标识（如临时预览类目录标注"md文件临时预览-请及时删除-超48小时没有访问则…"，提示自动清理规则）。
- 目录树下方设有独立的**"项目空间"**入口，与知识分类目录区分展示，可能对应团队协作项目维度的内容组织。
- 侧边栏支持**收起/展开**（通过边缘的箭头按钮"◀"折叠为窄条，节省主内容区空间）。

### 4.3 知识图谱可视化（首页核心亮点）
- 首页主体是一个**力导向气泡图（Bubble/Force Graph）**，用不同颜色、不同大小的圆形气泡代表各个知识条目/文档节点。
- 交互说明：页面明确提示"探索知识·点击气泡"，即**点击气泡可跳转至对应知识条目详情**。
- 气泡采用**多色系（蓝、粉、绿、橙、紫等马卡龙色）随机/分类着色**，用于视觉上区分不同类别或降低单调感，同时增强"知识网络"的可探索感。
- 气泡内文字为条目标题，标题过长时自动换行，气泡大小可能与内容热度/字数相关（需与产品确认具体规则）。
- 提供**"刷新图谱"**按钮，可重新生成/随机布局气泡位置，增加新鲜感和探索欲。
- 图谱节点示例：`Driver_Lamp`、`BLE Mesh基础知识`、`米家测试调试验收`、`串口产测指令说明`、`RTL8762E HO...`、`嵌入式周报统计说明`、`流程图-时序图怎么画`等，覆盖研发、测试、协议、流程规范等多类内容。

### 4.4 快捷操作工具栏
主内容区底部横向排列一组功能按钮，覆盖知识库的核心操作动线：

| 按钮 | 功能推测 |
|---|---|
| ➕ 创建术语 | 新建知识条目/术语解释 |
| 📤 导入 Markdown | 批量导入 .md 格式文档 |
| 📄 MD 转 PDF | 文档格式转换 |
| 🔒 涉密 PDF 转 MD | 针对涉密文档的格式转换（需权限控制） |
| 📦 文档包 | 批量文档打包下载/导出 |
| 📁 项目目录 | 跳转至项目维度的目录视图 |
| 🖥 本地 MD 预览 | 本地 Markdown 文件的在线预览 |

按钮均采用**同色系蓝底白字胶囊按钮**，视觉统一、层级清晰，属于高频操作的快捷入口。

### 4.5 AI 智能助手（悬浮窗）
- 位于页面右下角，默认以**悬浮小图标/收起状态**存在，点击展开为对话面板。
- 面板包含：标题栏"AI助手"（含最小化、关闭按钮）、对话展示区（默认提示"可以快速问我一个问题。"）、底部输入框（占位符"今天想跟AI聊点啥？"）、发送按钮。
- 提供**"基于知识库"勾选开关**，用于控制 AI 回答是否限定在知识库内容范围内（即 RAG 检索增强问答 vs. 通用问答模式切换）。
- 主内容区下方也存在一个**同功能的常驻输入框**（同样带"基于知识库"勾选与发送按钮），推测是同一 AI 能力在页面中的**双入口设计**（首页内嵌 + 悬浮窗），需与产品确认是否为同一会话状态同步。

### 4.6 底部状态栏
- 页面最底部展示团队文化标语（示例："产量是钱，质量是命；要钱更要命。"），起到品牌/文化宣导作用，非功能性交互区域。

## 5. 视觉风格规范

| 维度 | 说明 |
|---|---|
| 整体风格 | 扁平化、卡片式设计，简洁明快，符合企业内部管理系统调性 |
| 主色调 | 蓝色系为主色（按钮、图标、高亮文字），用于强调操作性元素 |
| 辅助色 | 气泡图谱采用多种马卡龙色（浅蓝、浅粉、浅绿、浅橙、浅紫）区分知识节点 |
| 背景色 | 页面主背景为白色/浅灰，保证内容区域的干净与可读性 |
| 圆角与阴影 | 气泡、按钮、卡片均采用较大圆角，整体视觉柔和；悬浮窗带轻量投影，突出层级 |
| 字体排版 | 中文黑体/无衬线字体为主，标题加粗突出，正文常规字重，层级分明 |
| 图标风格 | 线性图标（导航栏）+ 面性色块图标（左侧目录文件夹），风格统一 |

## 6. 交互细节与体验要点

1. **可折叠侧边栏**：兼顾信息密度与空间利用，用户可按需收起分类树，扩大主内容/图谱可视区域。
2. **气泡图谱的探索式交互**：区别于传统列表/树形目录的"查找式"体验，图谱提供"浏览式/发现式"体验，降低用户在庞杂知识库中的检索门槛。
3. **AI 助手双入口 + 知识库范围开关**：兼顾"精准问答（限定知识库）"与"通用对话"两种场景，满足不同问题类型的用户需求。
4. **临时文件生命周期提示**：如"md文件临时预览"目录明确告知48小时未访问自动清理规则，体现了对知识库整洁度的产品化管理思路，建议在交互上增加倒计时或到期提醒。
5. **快捷工具栏聚合高频操作**：将创建、导入、格式转换、导出等分散操作收敛到统一入口，减少用户跨页面跳转成本。

## 7. 待确认/待优化事项（建议）

- [ ] 气泡大小/颜色的具体分配逻辑（按热度、按分类、还是随机）需与产品明确，避免用户产生"颜色=分类"的误解而无对应图例。
- [ ] 首页内嵌 AI 输入框与右下角悬浮 AI 助手的会话状态是否同步，建议合并交互逻辑或明确区分使用场景。
- [ ] "涉密PDF转MD"等涉及权限的功能，需要在交互上明确权限校验与失败提示（如无权限时的禁用态/提示态设计）。
- [ ] 移动端/窄屏适配方案（当前为明显的桌面端宽屏布局，未见响应式说明）。
- [ ] 通知中心（铃铛图标）的详细交互（列表、已读/未读状态、跳转逻辑）需补充说明。
- [ ] 气泡图谱在节点数量大幅增加后的性能与可读性方案（如分层、聚类、搜索定位气泡等）。
