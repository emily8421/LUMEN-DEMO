## 0.2 任务概述

- **目标**：支撑团队知识沉淀与检索问答（详见 `docs/00-scenario.md` §1、`docs/03-prd.md` §3 路线图）。
- **运行环境**：本机单机 Demo / 生产部署（详见 `ai/project-rules.md` §2.1、`docs/env/local-env.md`、`docs/04-architecture.md` §4）。
- **条件与限制**：Phase 边界与非目标见 `docs/03-prd.md` §3/§5、`ai/project-rules.md` §1；导入降级 / 搜索增强 / 个人可用优先等约束见 §0.7 CON。

## 0.3 数据描述

- 系统核心数据实体（文档 / 空间 / 用户 / 权限 / 术语 / 标签 / 链接 / 切块等）领域模型见 `docs/06-db-design.md` §0.5（DIAG-DOM-01）——它是需求分析层「分析类图」性质的概念模型（对照 OO 方法论），是 06 物理表的概念上游。
- 物理表 / 字段 / 索引 / 数据词典权威见 `docs/06-db-design.md` §1/§2/§4。
- 数据安全与留存见 `docs/06-db-design.md` §5。

## 0.4 性能需求

- 资源软上限（内存 / 显存 / 磁盘）与运行形态约束：`ai/project-rules.md` §2.1、`docs/05-tech-spec.md` §5。
- 时间特性：检索 / 问答 / 导入响应目标与降级口径：`docs/05-tech-spec.md` §5、`docs/09-verification.md` 对应 TC。
- 数据精确度 / 适应性：随 Phase 细化，当前无硬性精度约束（详见 `docs/05-tech-spec.md`）。

## 0.5 运行需求

- 用户界面：桌面浏览器（Chrome / Edge）桌面端工作台（详见 `docs/design/frontend-interaction.md`、`docs/00-scenario.md` SC-006）。
- 软件接口：REST API 契约权威见 `docs/07-api-spec.md`（接口清单 / 请求响应 / 错误码 / 权限）。
- 硬件接口：无特殊外设依赖（桌面浏览器 + 本机或服务器资源）。
- 故障处理：异常 / 边界场景见 §0.7 EX；错误码见 `docs/07-api-spec.md` §3.4；出错处理设计见 `docs/04-architecture.md` §5.5。

## 0.6 其它需求

- 安全保密：数据安全 / 敏感字段 / 外部传输限制见 `docs/06-db-design.md` §5、`docs/05-tech-spec.md` §5.2、`docs/04-architecture.md` §1.1 信任边界。
- 可维护性：DB 权威 + 衍生数据可重建（`docs/decisions/ADR-010-...`）；编码基线见 `docs/05-tech-spec.md` §4.2。
- 可移植性：技术栈与运行时版本锁定见 `ai/project-rules.md` §2 / §2.5。
