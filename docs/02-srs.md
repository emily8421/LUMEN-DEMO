## 1. [P1] 本期需求规格（可验证）

### 空间与权限
- **REQ-001 [P1] 多空间隔离**：用户仅能访问其所属空间的文档；查询 / 检索 / 问答不得返回其他空间内容。
  验收：用 brightlite-team 账号查询，nova-internal 文档零命中。
- **REQ-002 [P1] 空间切换**：同一账号可在所属多个空间间切换，切换后上下文随之变更。
  验收：切换后首页 / 搜索 / 问答均只反映目标空间。
- **REQ-003 [P1] 文档权限分级**：文档可设 私有 / 团队共享 / 外部只读；私有仅作者可见，不进入检索 / 问答。
  验收：作者的私有文档，同空间其他成员搜索不到、问答不引用。

### 文档管理
- **REQ-004 [P1] 文档 CRUD**：可创建 / 读取 / 更新 / 删除 Markdown 文档。
  验收：四项操作均成功，删除后不可检索。
- **REQ-005 [P1] 行内编辑**：可在编辑器内对文档行内编辑并保存。
  验收：编辑保存后内容持久化，再打开内容一致。
- **REQ-006 [P1] 版本历史**：每次保存生成版本，可查看历史版本与差异、可恢复。
  验收：改 3 次后能看到 3 个历史版本，能恢复到指定版本。

### 检索与问答
- **REQ-007 [P1] 全文 / 语义搜索**：按关键词或语义相关查询返回当前空间可见文档，结果含标题 / 摘要 / 定位；语义召回基于已生成 embedding，zhparser 中文分词为可选增强，缺失时回退 `simple`。
  验收：搜索已知关键词或语义相近问题能返回正确文档；不得返回无权限文档。
- **REQ-008 [P1] RAG 问答**：基于当前空间可见文档回答，答案标注来源文档；无相关内容时明确告知而非编造。
  验收：问文档内事实 → 答案正确且标注来源；问文档外内容 → 回复"未在知识库找到"。
- **REQ-036 [P1] 术语管理**：每个空间可维护术语条目，包含标准名称、定义、客户习惯用语、负责人和状态；阅读 / 编辑时识别已定义术语，问答时优先采用当前空间术语定义并引用术语来源。
  验收：在 brightlite-team 新建「触发延迟」术语后，文档中该词可识别，问答解释优先使用该空间定义；同名全局术语不覆盖空间术语。

### 内容导入
- **REQ-009 [P1] 多格式导入**：Phase1 Demo 支持 `.md` / `.txt` 已提取文本导入，生成文档入库并参与检索 / 问答；真实 `.docx / .pdf` 解析留后续真实化。
  验收：导入 `.md` / `.txt` 已提取文本后能搜到、问答能引用其内容；真实 Word / PDF 解析不作为 Phase1 必过。
- **REQ-010 [P1] OCR 导入**：Phase1 Demo 以 OCR 预提取文本或人工已提取文本替代真实图片 / 白板 OCR；真实图片 / 白板 OCR 留后续阶段。
  验收：已提取文本导入后能搜到对应文字；真实 OCR 引擎、图片上传识别不作为 Phase1 必过。

### 访问
- **REQ-011 [P1] 桌面浏览器访问**：Chrome / Edge 桌面端可用全部 P1 功能。
  验收：桌面浏览器完成上述全部操作无阻断。
