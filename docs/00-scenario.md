## 1. 背景

LUMEN 是面向中小企业（典型：帮客户做 AI Agent 落地的初创公司 Nova）的团队知识库。
要解决的核心问题：

- 团队知识分散在聊天 / 邮件 / 桌面旧文件 / 个人笔记库中，难以沉淀与复用；
- 新人入职难以快速建立"这个项目 / 客户是怎么走到今天的"全貌；
- 部署方与客户团队需要既协作又隔离的知识空间（私有资产不外泄，共享资产可推进）；
- 存量知识能被 AI 检索与问答引用，而不必先做痛苦的数据迁移。

## 2. 目标用户

| 角色 | 典型身份 | 权限边界 |
|---|---|---|
| 部署方 / 管理员（Alice） | 系统部署方，持多个空间管理员权限 | 可在 nova-internal / brightlite-team 等空间间管理 |
| 客户团队成员（Lily 业务 / Mark 技术） | 客户方员工 | 仅能访问所属共享空间，其他空间不可见 |
| 新成员（Kira） | 刚入职 | 仅共享空间权限，靠 LUMEN 快速建立项目全貌 |

> 以上人物 / 公司 / 产品名均为虚构，仅用于场景演示。

## 3. 典型场景

- 登录后停留在所属空间，感知文档最近更新
- 同一账号下切换不同隔离空间
- 文档入库后，用 AI 问答获取结论并带来源引用
- 在编辑器内对文档行内编辑，保留版本历史
- 全文搜索 + AI 问答定位项目历史约束（如延迟下限），结果带来源
- 维护空间级术语表，问答时按当前空间术语解释客户习惯用语
- 拖拽导入 Word / PDF / 白板照片，提取文字 / OCR 入库
- 新人借助搜索与 AI 问答，快速建立项目全貌
