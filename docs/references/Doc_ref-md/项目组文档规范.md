## 图纸编号规范

1. 作图时统一使用相应的图纸模板，所用图符必须取自已建好模板中的图符。如在特殊情况下需要使用其它图符，必须申报组长。
2. 图纸编号规则：

```
图号 ::= <项目代称>-DWG<Category>-<Page of Total>-<Page>
<Category>       A；A类图纸（项目推进表）
<Page of Total>  总页数，共两位，不足位数前缀"0"
<Page>           本图序号，共两位，不足位数前缀"0"
```

## 文件命名规范

1. 组员共享使用「服务器」上的「<项目代称>」目录下的文件；
2. 服务器上提供的模板为作图或写文档的规范，为只读类型，组员使用必须先另存；
3. 文件命名规范（前缀）：

```
文件名 ::= <项目代称>-<Type>-<Subject>[-<Draft> | <Version>][-<Editor>]
```

其中：

**(1) Type（文档分类）**

| 类别码 | 含义 |
|---|---|
| DOC0 | 普通说明性文档、封面文档 |
| DOC1 | 会议记录文档、会议纪要文档 |
| DOC2 | 需求分析文档 |
| DOC3 | 概要设计文档 |
| DOC4 | 详细设计文档 |
| DOC5 | 编码调试文档 |
| DOC6 | 测试文档 |
| DOC7 | 用户文档 |
| DOC8 | 学术文档、关键技术报告，学位论文与答辩稿 |
| DOC9 | （保留） |
| DWGA | A类图纸（项目推进表） |
| DWGB | B类图纸（系统结构图、模型图） |
| DWGC | C类图纸（数据流图；用例图，交互图，活动图，顺序图、状态图） |
| DWGD | D类图纸（模块结构图；框架图，类图） |
| DWGE | E类图纸（流程图；对象图） |
| DWGF | F类图纸（组件图、部署图） |
| DWGG | G类图纸（保留） |
| TPL0 | 文档模板，项目规范文档 |
| TPL1 | 图纸模板 |
| TPL2 | （保留） |
| PPT | 电子讲稿类 |

**(2) Subject（主题）** ::= 文件内容主题的中/英文全称。要求文件名称的意义一目了然，项目中具体的正式文档命名请遵循有关规定。

**(3) Draft | Version（稿本或版本）** ::= 稿本描述串 | 版本描述串

- 稿本描述串（Draft）：编辑过程中用于区分不同内容或区分变化所使用的描述串。
  - 稿本的命名：`[-<Year><Month><Date>[-<No.>]]`，例如 `-20040905`、`-20041130-1`。日期号为修改时的当天日期，No 为当天开始计算的流水号（1、2、3 等）。
- 版本描述串（Version）：设计定型后发行过程中用于区分不同设计内容或区分变化所使用的描述串。
  - 版本的命名：`[-<Vn.m>]`，例如 `-V1.0`、`-V2.0`、`-V3.0`。

**(4) Editor（编辑者）** ::= 编辑者描述串：本次编辑结束时，用于标识该文件的最后编辑者所使用的描述串，由编辑者选用各自喜爱的代称，例如 `-<编辑者>`。注：只能是编辑者本人。

4. 文件命名示例：
   - 项目推进图：`<项目代称>-DWGA-项目推进图-20061101-0-<编辑者>`
   - 会议记录：`<项目代称>-DOC1-项目动员会议-20061101-0-<编辑者>`
