## 定位

- 模板属**其他项目的历史规范资产**，只作形态参考，不作为本项目流程权威；采纳任何骨架/规则须先经本项目确认。
- 方法论谱系：本套模板 = 结构化方法（SA/SD：数据流图+数据词典+结构图）与面向对象方法（Rose：类图/顺序图/用例）**混合**；`../软件系统面向对象开发方法的过程要点及关系.md` = 纯 OO 路线。两者对照使用。
- 转换脚本为临时脚本（TEMP 目录一次性执行，未登记 tool-registry；如需复用转正式工具须先检索注册表并登记）。

## 使用注意

1. 引用模板内容时以 `Doc_ref/` 原文为准；md 副本仅用于检索与粗读。
2. 模板中的排版指令（字号/页眉等）在 md 中保留为文字，不代表本项目排版要求。
