## 目录结构总览

| 类别 | 目录 | 说明 |
|---|---|---|
| 模板类·文档模板 | `<项目代称>\Template\Document` | |
| 模板类·蓝图模板 | `<项目代称>\Template\Blueprint` | |
| 文档类 | `<项目代称>\Document` | 子目录见下 |
| 项目推进图 | `<项目代称>\Project` | |
| 演示文档类 | `<项目代称>\Demo` | |
| 蓝图类 | `<项目代称>\Blueprint` | |
| 电子讲稿类 | `<项目代称>\Powerpoint` | 含 Audit 子目录及按需划分的子目录（如项目论证时期、项目实施阶段）；每次讲座之前的讲稿先存放在 Audit 中，等正式提交时再放入相应目录 |

| 个人工作内容类 | `<项目代称>\PersonalWork` | 个人整理后的文献、文献阅读笔记、研究文档（硕士开题、中期工作、论文工作等） |
