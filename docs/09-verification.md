## 1. 测试策略

- **单元测试**：service 层——权限过滤、切块、检索排序、导入解析
- **集成测试**：导入 → 检索 → 问答 端到端闭环（双空间、三级权限场景）
- **验收测试**：逐条 REQ 的可验证口径（见 §2 矩阵）
- **数据夹具**：`nova-internal` / `brightlite-team` 两空间 + 私有 / 团队共享 / 外部只读 各若干文档
