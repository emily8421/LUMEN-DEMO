# 详细设计：情报分析子系统（intelligence-analysis）

> v18 愿景新增的「情报分析（i2 精神）」支柱。整体为 `[愿景]`，多含高难度 AI，**待 05 技术验证后才决定是否纳入某 Phase**。
> 本文为**骨架**（global-rules §8）：各功能标"待验证 / 待细化"，不提前写死实现。
> 总体定位见 04（情报分析子系统行）；数据见 06（lumen_doc_participants / hypotheses / evidence / signal_subscriptions / doc_links）；接口见 07。

## 1. 职责

把分散在多份文档里的线索，按**关系、时间、因果、证据**聚合起来，支持分析师视角的"理关系、理时间线、理因果"。这是 v18 强调的远期差异化方向，也是高风险集中区。

## 2. 功能骨架（全部 [愿景]）

| 功能 | 说明 | 难点 / 待验证 | 追溯 |
|---|---|---|---|
| 多视角联动闭环 | 关联图节点 → 时间轴 → 事件因果展开 → 返回关联图，视图切换上下文保持 | 多视图间状态传递 | REQ-029 |
| 路径推理 | 指定两个文档，找多跳关联路径（关键词 / 实体跳转） | **高风险**：图算法 + 语义可解释性 | REQ-030 |
| 人物关系网络 | 以人物为中心聚合文档、共现人物、高频关键词 | 实体抽取（NER）质量 | REQ-031 |
| 矛盾检测 | 主动识别多份文档对同一指标描述不一致 | **高风险**：同名指标对齐、语义比对 | REQ-032 |
| 假设检验 / 证据地图 | 用户提假设，自动搜集支持 / 反对证据并分栏 | **高风险**：证据检索相关性、正反判定 | REQ-033 |
| 信号追踪 | 用户标记关注主题，新内容录入时自动匹配推送 | 主题匹配（向量 / 关键词）、增量索引 | REQ-034 |

## 3. 与其他子系统的关系

- **依赖** docs/design/rag-retrieval：证据搜集 / 路径检索复用检索能力
- **依赖** `lumen_chunks` / `lumen_doc_links`（P2）：图与检索的数据基础
- **依赖** 04 导航视图子系统（时间轴 / 关联图，P2）：多视角联动的视图载体
- 矛盾检测 / 证据地图 属于"重 AI 推理"，与 REQ-020 热力矩阵 / REQ-021 因果展开 同列高风险，须 05 先验证
