## 3. 核心流程 / 状态机

### Flow-D-TL-01：时间轴数据装配

- 触发：进入时间轴视图 → `GET /api/spaces/{id}/timeline`（带 `from?` / `to?` / `tag_ids?` / `density?`）
- 参与者：前端时间轴视图、API-033、`timeline` service、`lumen_documents` / `lumen_tags` / `lumen_doc_links`（或 `lumen_doc_timeline_events`，见 D-T-001）
- 输入：space_id、时间范围、标签过滤、是否返回密度
- 步骤：
  1. 鉴权 + 空间成员校验。
  2. 权限收敛：查询层限定当前用户可见文档集。
  3. 事件装配（数据来源见 §4 / D-T-001）：按文档 created_at / updated_at + 打标签 / 内链事件聚合为时间轴 items。
  4. 标签过滤：若传 `tag_ids`，交集过滤。
  5. 密度计算（REQ-024，`density?=true`）：按时间窗口（日 / 周）统计事件数 → 色阶映射。
  6. 大集合降级（见 §5）。
  7. 返回 `{items[{date,document_id,title,event_type,permission}], density?[]}`。
- 输出：时间轴 items + 可选 density
- 成功条件：仅含可见文档事件；密度色阶正确
- 失败 / 降级路径：事件数超阈值 → 时间窗口聚合 / 采样 / 提示切经典列表（逃生舱）
- 关联：REQ-013 / REQ-024 / API-033 / TC-P2-TL-001

> 时间轴为只读视图，无独立状态机（事件来自既有表的不可变历史，不引入新状态）。

## 5. 失败、异常与降级路径

| 场景 | 触发条件 | 系统行为 | 用户可见 | 阻塞验收 | 关联 TC |
|---|---|---|---|---|---|
| 大集合 | 空间文档 / 事件数超阈值（待 D-T-002 定） | 时间窗口聚合 / 采样；提示切经典列表 | 「数据较多，已聚合 / 切换列表视图」 | 否（降级） | TC-P2-TL-001 |
