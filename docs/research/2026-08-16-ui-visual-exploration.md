### 三套通用决策

- **代码块固定深色 `#1c1c1e`**（mintlify 模式，C-RA-002 候选）：三套统一，不随主题变——静态原型已按此渲染。
- 焦点环：A 实色 accent / B `#8fb0ff` / C `#c0593a`，全部 ≥3:1（UI 组件门槛）。
- 禁用态（`--faint`）豁免正文门槛（WCAG 对 disabled 元素不要求 4.5:1），记录实测值备查。
