## 6. 可读性根因（三文档通病）

1. **元信息超长**：03/04 的 §0 当前状态塞实现历史 → 应「一句话状态 + 历史指针」。
2. **信息重复**：03 功能讲 4-5 遍；02 REQ 表与 04 追溯矩阵互相重叠。
3. **表格过密无导读**：02 REQ 主表 50 行、04 §6 追溯 30+ 行，缺叙述性导读。
4. **职责混入**：02 REQ 表混实现方案；04 混 06/07 契约。
