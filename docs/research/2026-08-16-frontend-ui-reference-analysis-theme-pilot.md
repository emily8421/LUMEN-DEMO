## 1. UI brief 与问题定义

- **待设计的界面 / 流程**：LUMEN 全站主题层——`tokens.css` 单点令牌 → `[data-theme]` 多主题变体；覆盖工作区 / 文档详情 / 时间线 / 管理页等全部既有页面。
- **要解决的用户问题**：知识库工具的高频深色模式需求 + 视觉品格候选验证；同时验证「设计令牌单点 → 多主题」工程路径与母模板 UI 知识层的实际可用性（试点双重目的）。
- **已确认的输入偏好**（来自输入包 T-101..T-104 + 既有 brief）：
  - 3 套候选：A 浅色基线精修（对照组）/ B 深色 / C 品格方向（暖米纸，衔接 brief 既有「米白」候选 FEB-C-004）。
  - 不改信息架构 / 密度 / 文案方向；不新增 REQ / 接口 / 验收目标。
  - 两层评估都落盘 LUMEN `docs/research/`；机制层结论不自动回写母模板。
- **不在本次分析范围**：布局重构、组件库引入、移动端、IA 调整。

## 4. 采纳 / 调整 / 排除矩阵及理由

### 4.1 知识库模式

| 引用 ID | 决定 | 项目化改写 | 理由 | 回填位置 |
|---|---|---|---|---|
| `PAT-VIS-005` | 采纳（硬门槛） | 三套主题全 token 组合过对比度计算：正文 ≥4.5:1、大字 / 组件 ≥3:1；不过即改 | A 级基线，可程序化验证（评估第 1 层可读性维度） | 视觉探索验证项 + 评估文档 |
| `PAT-VIS-001` | 采纳（约束） | 主题只改色板；层级信号（字号 / 字重 / 间距）三套完全一致 | 防止「换主题 = 重排版」扩大改造面 | 实现约束 |
| `PAT-VIS-003` | 采纳（约束） | 导航高亮 / 面包屑 / 当前项指示在三套主题下逐一核对可辨 | 深色下导航信号最易失辨 | 切换正确性检查项 |
| `PAT-VIS-006` | 采纳（约束） | 断点行为与主题正交，不改 `responsive.css` | 主题层与布局层分离 | 实现约束 |
| `PAT-VIS-004` | 排除 | — | 不适用条件命中：数据密集工作台首屏是数据本身 | 不回填 |

### 4.2 D 级案例观察（输入包 §3，9 案例逐条）

| 案例 | 决定 | 理由 |
|---|---|---|
| linear | 采纳为 B 套主参照 | 「一个强调色 + 中性阶梯 + 1px 发丝线」纪律配方，正对深色工作台 |
| raycast | 采纳为 B 套语义色参照 | 15% 透明度软底直接映射 LUMEN 既有 `--*-soft` 令牌结构 |
| sanity | 采纳为 B 套结构纪律参照 | 「中性阶严格无彩 + 统一激活色」保证深色下信号一致 |
| warp | 采纳为 C 套深色版衔接参照 | 暖炭画布证明深色 ≠ 蓝灰一种 |
| claude | 采纳为 C 套主参照 | 「暖纸底 + 珊瑚点」是知识 / 文档产品成熟品格方向，衔接 brief 既有米白候选 |
| notion | 采纳为 A 套参照 | 主界面收敛彩色用量、彩色只留给数据标记 |
| mintlify | 采纳为通用决策参照 | 「正文随主题、代码块固定深色」可显著降低主题改造面（涉 C-RA-002） |
| vercel | 备选（不启用） | 高对比中性方向留作 C 套备选人格；本试点 C 套主走暖米纸（C-RA-001） |
| superhuman | 排除 | 营销气质重，工作台借鉴点少（记录排除理由） |

## 5. 页面 / 流程 / 状态 / 恢复 / 可访问性 / 响应式输入

- **页面与流程**：视觉探索覆盖工作区列表页 + 文档阅读页两个关键页面；实现期切换正确性覆盖工作区 / 文档详情 / 时间线 / 管理页截图矩阵。
- **关键状态**：加载 / 空 / 错误 / 权限提示在各主题下语义色区分度逐一核对（success / warning / error / info + hover / disabled 不可混）。
- **错误恢复与撤销**：主题切换即时可逆（localStorage 持久化，C-RA-003）；无不可逆操作。
- **可访问性**：PAT-VIS-005 硬门槛（对比度计算全 token 组合）；语义状态不只靠颜色（沿用既有图标 / 文字惯例，主题层不弱化）。
- **响应式**：断点行为与主题正交（PAT-VIS-006 约束），不改 `responsive.css`。

## 6. 视觉方向与明确禁区

- **视觉方向**：
  - **A 套（对照组）**：保持 `#f4f6f9` 基底与 `#2563eb` 主色；收敛 `--blue-soft` 类软底使用面（彩色只留数据 / 状态标记，notion 参照）；统一 hover 激活信号（sanity 单一激活色纪律）；代码块固定深色面（mintlify 模式）。
  - **B 套（深色）**：近黑画布 + 面板 3 级阶梯 + 4 级文字阶梯 + 发丝线 `rgba(255,255,255,0.08)`；语义色提亮一档 + 12-15% 软底（raycast 配方）；主色 `#2563eb` 提亮变体保持品牌连续性（linear 结构纪律）。
  - **C 套（暖米纸）**：暖纸画布 `#faf9f5` + 白 / 暖沙面板 + 暖墨 `#1c1b18` + 珊瑚 / 赭主色 + 暖发丝线（claude 主案 + warp 深色版衔接）。
- **明确禁区**（承接 brief 既有结论）：大面积黑色导航块；实体公告板拟物（牛皮纸 / 图钉 / 手写体）；营销页大留白风。

## 7. 冲突 / 待确认项 / 需用户研究验证的假设

| ID | 待确认项 | AI 建议 | 建议依据 | 阻塞关系 |
|---|---|---|---|---|
| `C-RA-001` | C 套人格方向：暖米纸（claude）vs 高对比中性（vercel） | 暖米纸 | 衔接 FEB-C-004 既有「米白」候选，不是凭空发散；vercel 冷峻人格与知识工作台调性距离更远 | **阻塞视觉探索范围**（C 套出图方向） |

| `C-RA-003` | 主题持久化与首帧闪烁（FOUC）策略 | 实现期再定（localStorage + 内联预置脚本候选） | 属工程细节，不影响视觉方向评审；实现时按主流实践（`prefers-color-scheme` + 用户覆盖 + 内联预置）落地 | 不阻塞探索 |
