## 3. 推荐范围（AI 建议·待人工确认）

### 3.1 Phase2 MVP 核心（建议纳入，5 项）
- **REQ-012 标签视图**
- **REQ-026 内部链接 + 反向链接**
- **REQ-014 AI 润色 + 写作侧边栏引用**
- **REQ-025 快速录入索引条目**
- **REQ-027 单文档导出 PDF**

> 理由：均**延伸 Phase1 已验证底座**（文档 / 权限 / 检索 / RAG / LLM），新真实依赖风险低（仅 PDF 库、可能的写作流式），落地「知识组织 + 写作辅助 + 交付」的 MVP 价值。

### 3.2 Phase2 可选 / 子范围（视精力与验证）
- **REQ-013 时间轴视图（先不做关联图）** + **REQ-024 密度热条（跟随 013）**：若时间允许且布局算法经验证，可作为 MVP 扩展；否则整体延后。

### 3.3 延后（Phase3 或愿景前，需独立 tech-env-eval）
- **REQ-016 多人协作**：实时并发依赖重；建议 Phase2 用「评论 / 编辑锁」子范围替代实时共编，真实协作留 Phase3。
- **REQ-017 跨设备 / 移动端**：建议 Phase2 仅做桌面响应式，真实移动端 + VPN 留后续。
- **REQ-015 跨空间推送**：安全敏感的副本模型，建议延后；Phase2 可用「单向外链」子范围替代。
