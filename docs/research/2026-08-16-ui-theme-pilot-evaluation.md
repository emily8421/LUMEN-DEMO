|---|---|---|---|

| dark | 全过（最低主色 on 面板3 4.89） | 全过（焦点环 8.53） | **通过** |
| paper | 全过（最低主色文字 on coral-soft 4.67+） | 全过（焦点环 4.44） | **通过** |
| legacy | 正文过（15.03）；**muted on 画布 4.40、焦点环 1.68 为历史缺陷留证** | — | **按设计豁免**（冻结对照主题，缺陷留证不改，brief §3.1.1 已标注） |

### 1.2 语义色区分度

方法：四套主题下 success/warning/error/info 语义色 + hover + disabled 组合在 smoke 中实测背景色切换正确；软底色（`--*-soft`）与语义色前景逐一配对过对比度计算（§1.1）。语义状态在既有 UI 中均带图标/文字辅助（不只靠颜色），主题层未弱化该惯例。

结论：**通过**——四套下四语义色互不混淆（dark 套提亮一档 + 13-14% 软底、paper 套暖底重校后区分度实测可辨）。

### 2.3 D 级封顶规则实效

- 实际作用：案例配方只进入「视觉方向启发」（B 套结构纪律 = linear、软底 = raycast、C 套 = claude、代码块固定 = mintlify），**所有落地值均经 A 级门槛（WCAG 计算）重校**——4 处修订证明 D 级起点值不可直接用，「D 级发散 + A 级验收」分层真实有效。
- 压力场景：出现 1 次——C 套主色 #c96442 观感最佳但文字场景 3.7:1 不过线；按规则弃用为文字色、降档为按钮底。**未发生拿 D 级对抗 A 级的情况**（封顶规则未受压）。
- 无「案例观察被写成成熟结论」的越界。

### 2.4 令牌化路径复用性（回流候选）

「CSS variables 单点定义 → `[data-theme]` 变体切换 → 组件文件零字面色值 + CI 守门」路径在真实中项目（29 CSS 文件 / 202 处欠账）验证可行，增量结论超出单点 token 常识的：

1. **欠账分布有年代分层**（新文件全 var()、老文件全字面）——清零可按文件级排序（本项目 local-mount 两文件 54 处即大头）。
2. **遮罩/阴影必须整值令牌化**（`--shadow-*`/`--overlay`），逐 rgba 保留字面会在 dark 主题穿帮（阴影在深色下需更深）。
3. **语义色 border/soft/hover 三件套成套收编**（`--red-border` 等），只收主色会留半截硬编码。
4. **焦点环实色优于透明混色**（跨主题对比度可控）。
5. **代码块固定深色**显著降低 markdown 渲染面改造量（知识库类产品可复用决策）。

**回流判断**：以上够格提炼为 `PAT-VIS-*` 候选（如「多主题令牌化改造路径」）；按 §2 节边界，本项目只产材料不回写——建议母模板收到本文件后评估是否起草提案（跨仓决策）。
